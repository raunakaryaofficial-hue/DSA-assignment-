Algorithm: Merge Two Sorted Linked Lists

Input: Two sorted linked lists (e.g., L1 and L2 containing values like 10, 20, 25, 40, 50, 70, 80).
Output: A single merged sorted linked list.

1. Start with the head pointers of both sorted lists, L1 and L2.
2. Create a dummy node to act as the start of the merged list, and a pointer 'current' pointing to dummy.
3. While both L1 and L2 are not NULL:
   a. Compare the data of L1 and L2.
   b. If L1->data <= L2->data:
        - Attach L1 to current->next.
        - Move L1 to L1->next.
   c. Else:
        - Attach L2 to current->next.
        - Move L2 to L2->next.
   d. Move current to current->next.
4. If L1 is not NULL, attach the rest of L1 to current->next.
5. If L2 is not NULL, attach the rest of L2 to current->next.
6. The merged list starts at dummy->next.
7. Stop.
